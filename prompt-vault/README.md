# Prompt Vault

Team library for Midjourney images, published as a claude.ai Artifact:
https://claude.ai/artifact/1NjU4zVKxuVU3zNkBUYMDH

- Upload (button or drag & drop) — editors only. Prompts/params are read from Midjourney PNG metadata.
- Masonry grid with adjustable thumbnail size, search by name or prompt.
- Folders and subfolders (create, rename, move, delete; drag images onto folders).
- Personal favourites (stored per person).
- Multi-select download as ZIP (keeps folder structure for "Download folder").

`index.html` is the published source. Republish it with the Artifact tool to update.
