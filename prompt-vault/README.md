# C&T Stacks

Team gallery for Midjourney images, published as a claude.ai Artifact:
https://claude.ai/artifact/1NjU4zVKxuVU3zNkBUYMDH

- Home: grid of stacks (3 fanned photos + name). Dashed "+" card creates a new stack.
- Upload: drag images from the desktop onto a stack (or into an open stack, or the blue button).
- Stacks nest (stacks inside stacks). Drag a stack to "pin to the top", or onto another stack to nest it.
- Inside a stack: tilted, rounded tiles. Favourites are shared and lift images to the top.
- Select 2+ images → ZIP download. "Download all" keeps the sub-stack folder structure.
- Share: generates a 1200×630 preview card (tool name, gallery name, 3 photos) + a direct link.
- Space settings: name and background colour; UI text colour is chosen automatically to pass WCAG AA.
- Prompts and parameters are read from Midjourney PNG metadata.

`index.html` is the published source. Republish it with the Artifact tool to update.
