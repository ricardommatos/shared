# shared

## Bancada

Versão pessoal de um to-do "agêntico" (inspirado no Calesto): pedidos do Gmail,
Slack, Google Calendar e Granola viram tarefas, e um agente adianta o trabalho
(rascunhos, resumos) sem nunca enviar nada.

- `bancada/index.html` — painel publicado em https://claude.ai/artifact/97awqezjzAsWChyaD7gyf5
  (guarda as tarefas na base de dados do artefacto: `tasks/*` e `meta/latest`).
- `bancada/agente.md` — instruções da rotina "Bancada", que corre às 08:22 e
  14:22 (Lisboa), de segunda a sexta.
