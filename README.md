## designRun

A pasta [`designRun/`](./designRun) contém uma cópia do [designRun](https://github.com/mtthw-blfrmn/designRun) (commit `e1743f5`), um espaço de trabalho local para design de produto com agentes de IA.

**Como usar no Mac**

1. Descarregar este repositório (Code → Download ZIP) ou cloná-lo.
2. Abrir a pasta `designRun/` (não a pasta `app/`) no Claude Code.
3. Para a interface visual (precisa de Node.js 22.13+), no Terminal, dentro de `designRun/`:

   ```bash
   npm ci
   npm run dev
   ```

   e abrir http://127.0.0.1:4100

O guia original está em [`designRun/START-HERE.md`](./designRun/START-HERE.md).
